# ayanali.tech

Personal research portfolio of **Ayan Ali Saleem** — robotics & AI researcher
(3D perception, depth-supervised NeRF, A*–DWA–MPC autonomous navigation).

- Live site: https://ayanali.tech
- Single-page static site: `index.html` + `style.css` + `script.js`, served by
  GitHub Pages from this repository.
- Preview locally: `python3 -m http.server` in this folder, then open
  http://localhost:8000

This repository holds website code only. No CVs, certificates, letters, or
other personal documents live here.
